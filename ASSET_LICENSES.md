# Asset register

All four learning illustrations are original SVG vector artwork created specifically for this Noor project and stored locally in `public/images/`:

- `wudu.svg` — original ablution vessel and water illustration.
- `salah.svg` — original prayer mat and mihrab illustration.
- `ghusl.svg` — original flowing-water illustration.
- `kalimas.svg` — original open-book and geometric ornament illustration.

No external image URLs, remote stock photos, or third-party image attributions are used by the Learn section. The SVG `xmlns` declaration is a technical XML namespace, not an external image fetch.


## Typography and UI assets
- Kalima Arabic text and its English transliteration/meaning are editorial text, not image assets. Text reference: Learning Quraan, “The Six Kalimas: Arabic, Transliteration and Meaning” (Madani Panj Surah-style collection), https://www.learningquraan.co.uk/guides/6-kalimas/ (accessed 13 Nov 2026). Hindi meanings are original translations prepared for this interface and require scholarly review.
- Search and navigation icons are rendered from lucide-react; package license is ISC.
- Arabic display font Amiri is loaded through Google Fonts in `index.html`; network access is required for that web font. System Arabic fallback remains available.
